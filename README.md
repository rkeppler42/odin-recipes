## 🇺🇸 English

A recipe website built as part of [The Odin Project](https://www.theodinproject.com/) curriculum, focused on practicing raw HTML — page structure, links, lists, and embedding images.

### 📋 Project Structure

```
odin-recipes/
├── index.html
└── recipes/
    ├── recipe-1.html
    ├── recipe-2.html
    └── recipe-3.html
```

### 🧩 Iterations

- **Iteration 1 — Initial structure:** `index.html` with HTML boilerplate and a main heading.
- **Iteration 2 — Recipe page:** `recipes/` directory, first recipe page, and navigation links between pages.
- **Iteration 3 — Recipe content:** image, description, unordered ingredients list, and ordered steps list.
- **Iteration 4 — More recipes:** two additional recipes with the same structure, linked from `index.html` via an unordered list.

### 🚀 How to view

**Live:** [rkeppler42.github.io/odin-recipes](https://rkeppler42.github.io/odin-recipes)

**Locally:**

```bash
git clone https://github.com/rkeppler42/odin-recipes.git
cd odin-recipes
# Open index.html in your browser
```

## 🇧🇷 Português

Projeto de receitas desenvolvido como parte do currículo do [The Odin Project](https://www.theodinproject.com/), focado na prática de HTML puro — estrutura de páginas, links, listas e incorporação de imagens.

### 📋 Estrutura do Projeto

```
odin-recipes/
├── index.html
└── recipes/
    ├── recipe-1.html
    ├── recipe-2.html
    └── recipe-3.html
```

### 🧩 Iterações

- **Iteração 1 — Estrutura inicial:** criação do `index.html` com boilerplate HTML e título principal.
- **Iteração 2 — Página de receita:** criação do diretório `recipes/`, primeira página de receita, e link de navegação entre páginas.
- **Iteração 3 — Conteúdo da receita:** adição de imagem, descrição, lista de ingredientes (não ordenada) e lista de passos (ordenada).
- **Iteração 4 — Mais receitas:** duas receitas adicionais com a mesma estrutura, listadas na `index.html` com uma lista não ordenada.

### 🚀 Como visualizar

**Online:** [rkeppler42.github.io/odin-recipes](https://rkeppler42.github.io/odin-recipes)

**Localmente:**

```bash
git clone https://github.com/rkeppler42/odin-recipes.git
cd odin-recipes
# Abra index.html no seu navegador
```
